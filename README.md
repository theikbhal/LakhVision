# LakhVision

**₹20,00,000 in 2 Years — Visual Goal App** (macOS, Swift/SwiftUI)

Built for a Tirupati, Andhra Pradesh household goal set by wife: reach ₹20 lakhs in 2 years after 4 years with no job and no self-earning income.

## Features

1. **Many ways to visualize the goal pass-mark** — ring, thermometer, money bar, days split, pass-mark ladder (25/50/75/100%), pace vs time; ₹20L target highlighted at top
2. **Currency notes** — visualize saved + goal in **₹500 / ₹200 / ₹100** note stacks with optimal mix
3. **Anything** — car, house visualizations
4. **Gold** — grams you can buy (rate editable)
5. **Farmland** — acres near Tirupati, AP (price editable)
6. **Tractor, Auto, Car** — thing cards with affordability progress
7. **Why card** — wife set the goal · no job 4 years · no self income
8. **Menu bar** extra — saved · % at a glance
9. **Push notifications** — daily visit, weekly minimum, monthly worst-case
10. **Installed to** `/Applications/LakhVision.app`
11. **GitHub repo** — https://github.com/theikbhal/LakhVision
12. **Mac app (Swift)**
13. **Check cadence** — daily visit · weekly minimum · worst case once a month
14. **Registered in AppTracker** (Applications tracker, not Project Tracker)

## Quick start

```bash
./Scripts/install.sh
```

## Notifications

- Daily at 09:00 (visit the app)
- Weekly Sunday 10:00 (minimum weekly check)
- Monthly 1st at 11:00 (worst case: once a month)

## Data

`~/.lakhvision/goal.json`

## Build

```bash
./Scripts/build.sh
open build/LakhVision.app
```
